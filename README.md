# Hollow Godot Player for iOS

A iOS app that lets you import and play Godot games directly on your iPhone without needing to rebuild the app for each game.

Supports Godot 3 and 4, with features like:

- Importing `.pck` files through the Files app
- Customizable on-screen buttons, joysticks, and mouse controls
- Keyboard and controller support
- Portrait and landscape modes
- Per-game saves and settings
- Built-in cheats and a console
- Spine support for compatible games

Not every game will work, especially ones that depend on unsupported native extensions or specific engine features. Some newer features are still untested on actual devices.

## How to build

1. Idk ask gpt

The app requires iOS 15 or later. If you're updating an existing installation, keep the same signing identity and bundle ID to preserve your saves.
